# Telos — Frontend

The web interface for Telos, a cross-chain yield-strategy marketplace where users discover vaults, explore strategies, and access DeFi yield opportunities.

### Features
- Vault discovery and strategy exploration
- Wallet authentication with Privy
- Vault creation and creator-fee configuration
- Deed marketplace for transferring vault ownership and associated fee rights
- Strategy discovery and AI-assisted insights

### Tech Stack
React · TypeScript · Vite · Privy

### Development
```bash
cd telos
npm install
npm run dev
```

Configure the required environment variables before connecting to the API and supported networks.
